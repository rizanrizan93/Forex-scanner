# Small-stop research source/evidence

All code is offline and contains no order sender. Place the stated raw XAU M1 source under datasets/data_audit/XAUUSD_m1.csv relative to this directory. Generate initial zones/features with reversal_search_v2/prepare_zones.py and enrich.py. The following stages use those files: reversal_search_v3/search.cpp (smaller stops, both sides), search_phase2.cpp (new masks), search_phase3.cpp (SELL sessions). Phase2/3 require the extra 32-bit context masks described in protocol_phase2 and the source report. Generate M5 zones/features using reversal_search_v4/prepare.py and enrich.py; search.cpp there uses the extra masks. These stages are adaptive retrospective searches, not independent validation. See ../xau_small_stop_sell_search_20261024.md for outcomes and exact limitations. Full grid tables and raw/binary datasets are reproducible intermediates, not included.

The original impulse SL15 candidate (buy_audit.json) is rejected because Q1 2026 PF0.409. The dashboard research prealert instead uses FVG M15 SL20/TP25, cost/latency audits included. No SELL configuration passed the declared gates. Evidence includes failed frontiers, not only winners.
