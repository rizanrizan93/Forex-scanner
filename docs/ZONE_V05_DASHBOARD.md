# V05 dynamic zone dashboard

XAUUSD → Zona reversal → V05 card. Dashboard research references only; no cBot imports, execution authority or execution influence. This does not replace the older manual map.

Every closed M5 produces BUY and SELL decisions: ENTRY only for a fresh completed setup; otherwise TIDAK_ENTRY with a reason. WATCH states distinguish first touch, M15 reclaim and subsequent M5 BOS. Completed M15 and M5 candles only. Collector cadence is aligned to five-minute boundaries +2 seconds. A complete historical tick window establishes the first BID of the new M1 and ASK already known at that tick; this opening price point is used without reading forming-candle high/low/close. Missing or truncated tick windows keep WATCH/BLOCK. There is no mandatory one-minute wait. Collection/network time adds delay; this is not a zero-latency execution service. The panel checks every 10 seconds. Missing the latest expected M5/M15 close hides price levels and entry. Snapshot age cap is 420 seconds and future timestamps are rejected. Other dashboard refreshes are unchanged.

Frozen candidate: H1 EMA20 ±0.15 prior ATR14, strength >=0.6, first-touch age <=24h; first M15 reclaim followed by subsequent M5 break of previous three contiguous M5 extremes and directional reclaim, within 120min. Distal SL buffer 0.20 ATR; no chase beyond 0.75 ATR; RR net >=1.5; risk >=3 proxy costs; entry window 07–17 UTC /14:00–23:59 WIB; max24h. One reference position at a time. New ENTRY becomes AKTIF_REFERENSI after one five-minute window, then SELESAI on first SL/TP/timeout (SL first for ambiguous minutes). This is simulated reference tracking, not broker positions.

At first touch, B is the nearest already-formed, valid opposing H1/H4 node within120h and0.25–20 sourceATR. TP is0.025 sourceATR before B. Node definitions ported from original V05: OB,FVG,breaker,breakout,previous-day extremes,EMA,swing. Node registry preserves published geometry across rolling history refreshes/restarts; new candle formations can add new zones. A setup's target does not trail changing EMA prices. A restart restores the previous registry from the snapshot branch. Native limited-window EMA initialization can differ from full-history research; full native parity is not claimed.

The read-only collector requests historical BID and ASK ticks around each recent reference entry. Only ASK already known at the observed opening BID, or quotes known at/before an existing M1 open, and <=20 seconds old qualify; missing/truncated/crossed quotes block ENTRY. Proxy roundtrip fee/slippage remains0.17 USD/oz in addition to entry spread. These are operational cost estimates, not proof of future fill prices. Quote lookups are bounded to8 recent setups per collection. Unquoted setups remain BLOCK.

BUY A → SELL B → BUY C → SELL D is NOT a validated strategy. B is a target, not an automatic opposite entry. B can become WATCH, but a subsequent trade must independently qualify under the engine's EMA-source and M15/M5 rules. A pivot target that is not an eligible EMA source does not automatically gain eligibility. C/D are not fabricated before qualifying zones exist. Alternation is optional; WAIT is valid. Any full conditional-chain extension requires separate research, not relabeling this candidate.
