# Frozen layering 100,000 configuration search

Offline research, with no broker, scanner, database or dashboard authority.
Start from the original frozen signals and preserve initial absolute SL/TP,
holding expiry, native minimum lot and maximum risk/margin. No signal-family
optimization or lead–lag continuation.

Install `pip install -e . -r requirements-layering-research.txt`.
Use the original input layout from `FROZEN_LAYERING_REPLAY.md`.

```bash
python scripts/research_layering_100k.py --symbol XAUUSD --data /path/to/frozen-archive --cache /path/to/private-cache --output research/results/layering_100k_xauusd.json
python scripts/research_layering_100k.py --symbol EURUSD --data /path/to/eur-parquet --cache /path/to/private-cache --output research/results/layering_100k_eurusd.json
python scripts/validate_layering_100k.py --symbol XAUUSD --data /path/to/frozen-archive --cache /path/to/private-cache --result research/results/layering_100k_xauusd.json --output research/results/layering_100k_xauusd_validation.json

python -m pytest tests/test_layering_grid.py tests/test_distributed_layer_replay.py -q
```

## Exact grid

1000 fill schedules: 10 deepest stages between .15R and .90R; 2–6 stages;
limit or completed H1/M15/M5 reversal; TTL 15/30/45/60/90/120/150/180/210/240min.
100 sizing policies: initial fraction .2/.4/.6/.8/1 of original child count;
depth weights power 0/.5/1/1.5/2; reserve original planned USD or frozen risk cap;
optional half risk budget after CLOSED equity DD >=10%. Quantity always respects
frozen native risk/margin ceilings; stops never widen.

The exact Cartesian grid contains 100,000 distinct parameter sets per symbol,
200,000 symbol-account experiments total, plus baselines. Native lot rounding
means many parameter sets have identical realized summaries. They are not
100,000 independent alpha discoveries.

Fill schedules and known M1 quotes/equity mark coefficients are cached, and
compiled accounts still replay M1 marks, integer children, floating-equity margin,
carry, execution cursor and compounding. Caching avoids repeating feature
calculations; it does not replace M1 DD with closed-equity DD. Five configurations
per symbol are checked by independent scalar, position-by-position accounting.

Each schedule attempts at most one stage per fresh completed reversal, including
zero-quantity attempts. Market adds use current observed quote, never the prior
trough. Limits cancel at invalidating opens and at potentially earlier TP; limits
crossed before an intrabar stop incur STOP_FIRST losses. Invalid/time/gap exits
cannot add. Additional XAU children may exceed the original balance-step desired
count in research but not the original total risk/margin cap. Degear only reduces
budget. EUR virtual feedback stays unchanged.

EUR M1 peak marks use aggregate floating PnL rather than clamping each child's
negative unrealized excursion away. XAU uses the frozen adverse-then-close marker.
Both baselines reconcile original ending balance, PF, count and DD exactly.
Neither method reconstructs exact tick order. Reference leverage 100 and costs
are synthetic frozen assumptions, not historical broker ASK/fill observations.

Selection uses 2016–2024 prefix higher balance + lower M1 DD, PF>=95% and
frequency>=75% baseline, then lowest train DD, highest train balance. Identical
annual prefix summaries are deduplicated, without claiming identical tick paths.
Seven expanding folds select from prefix data only; validation starts with the
same causal baseline cash. 2025 is retrospective temporal validation because
this history and the original optimized baseline were already seen. Full-sample
winners are clearly posthoc diagnostic candidates and are never used as evidence
of an untouched holdout. No multiple-testing-adjusted significance claim is made.

Robustness compares baseline, train winner and diagnostic winner under paired
costs x1.5/2/3, confirmation delay 1/5/10min, 1% execution quote removal and 10%
opportunity removal. Offline confirmations remain available during quote removal;
this is not complete live feed-failure simulation. Parameter neighbors alter one
grid dimension. Bootstrap: 500 paired 5-trade blocks. Monte Carlo permutes fixed
historical percentage returns; it is not full re-sizing under altered ordering.

Matrices `.npz` contain all 100,000 account rows and annual prefix metrics, and
are preserved in the evidence archive instead of adding 22MB of generated binary
data to the code repository. File and implementation hashes are in the manifest.
Use `allow_pickle=False` to read NPZ. Private pickle caches are generated by this
script only; never load downloaded/untrusted pickles as private caches.
